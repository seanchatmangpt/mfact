# No Ambient Test Authority

A test acquires authority only over the exact proposition or observable it checks.

## Forbidden promotions

- `lake build` passed → product theorem proved.
- `#guard` passed → kernel proof.
- finite world passed → universal theorem.
- theorem exists → theorem is on the crown path.
- theorem count increased → mathematical progress.
- snapshot unchanged → semantics preserved.
- two records have identical fields → correspondence.
- `.par` exists → events commute.
- no `sorry` token in source → no `sorryAx` dependency.
- nonempty receipt ID list → valid receipt ancestry.
- first failure → minimal counterexample.
- benchmark looks linear → O(n).
- generated artifact has a name → provenance established.

## Mandatory LLM sentence before promotion

> This evidence establishes **[exact proposition/observable]** on **[carrier/domain]**
> using **[mechanism]**. It does not establish **[nearest tempting overclaim]**.

The sentence belongs in the working analysis or test metadata. It need not be emitted
as repetitive source prose when the same facts are mechanically encoded.
