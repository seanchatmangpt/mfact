# Agent Handoff Checklist

Before handing test code to the next compiler agent:

- [ ] Every test has a `Tnnn` ID and stable `MFW.TST...` instance name.
- [ ] The exact family/type is correct.
- [ ] Controlled carrier is named.
- [ ] Law/observable is stated.
- [ ] Evidence class is stated.
- [ ] Claim ceiling is stated.
- [ ] Positive witness exists where applicable.
- [ ] Negative/refusal witness exists where applicable.
- [ ] Countermodel obligation is resolved or explicit.
- [ ] Metamorphic relation is resolved or explicit.
- [ ] Mutation killer is resolved or explicit.
- [ ] Composition neighbor is named.
- [ ] Flow membership is named.
- [ ] Replay relevance is named.
- [ ] Standing-path edge is named.
- [ ] No runtime/FFI/cloud consumer obligation has leaked into mfact scope.
- [ ] No source lexical count is presented as kernel evidence.
- [ ] No first failure is called minimal without a minimum witness.
- [ ] No `.par` syntax is called concurrent without commutation/independence.
- [ ] No golden/snapshot result is called a theorem.
- [ ] No finite result is promoted to general proof.
- [ ] No verifier can pass with an empty required check set.
- [ ] Build status remains `NOT_RUN` until another agent actually invokes Lean/Lake.
