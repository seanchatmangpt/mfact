# LLM Constitution for Lean/Lake Test Manufacture

## Mission

Manufacture tests for mfact and Multifractal Workflow without collapsing distinct
evidence classes into generic `example` declarations.

The controlled mfact boundary is:

`TTL → ggen → Lean 4 → Lake → auditor`

The correctness of a downstream runtime, cloud implementation, FFI, subcontractor,
or consumer is outside mfact's proof obligation. Test correspondence only for maps
inside the controlled boundary.

## Non-negotiable laws

1. A test name grants no authority.
2. A compiled file is not automatically a tested claim.
3. `#guard` is executable evidence, not a kernel theorem.
4. Finite verification is not general proof.
5. A first counterexample is not a minimal counterexample.
6. A `.par` constructor is not a proof of concurrency.
7. A golden file is not a semantic theorem.
8. An object named `Receipt` is not a verified receipt unless its law and admission
   surface are proved.
9. Never infer a correspondence from similar field names.
10. Every crown claim is evaluated by required admitted edges, not declaration count.
11. Every escaped defect manufactures a permanent regression witness.
12. Every crown capability uses the Eleven-Witness Crown Matrix.

## Evidence classes

- `KERNEL_PROOF`
- `COMPILED_ENVIRONMENT_AUDIT`
- `FINITE_DECISION`
- `UNTRUSTED_EVALUATION`
- `GENERATED_FALSIFIER_SEARCH`
- `GOLDEN_DRIFT_SIGNAL`
- `BENCHMARK_MEASUREMENT`
- `STRESS_BOUNDARY`
- `EXPLICIT_GAP`

A test must state exactly one primary evidence class and may list supporting classes.

## Standing promotion

`CANDIDATE_ONLY`
→ evidence collected
→ exact test family obligations satisfied
→ neighboring edges checked
→ crown matrix reconciled
→ environment-derived audit
→ `ALIVE` only when the declared standing path is complete.

Never promote standing from file count, theorem keyword count, passing grep, or prose.
